# Student Marks

This project is a beginner-friendly C program that stores student details, marks, total, average, grade, and supports searching and sorting.

## Features

- Enter student name and roll number
- Input marks for Physics, Chemistry, Math, English, and CS
- Calculate total and average marks
- Assign a grade based on average
- Display all students
- Search for a student by name
- Sort students by total marks (highest to lowest)

## How to Run

```bash
gcc student_marks.c -o student_marks
./student_marks
```

## Example

--- Student 1 ---
Enter Name: Alice

Enter Chemistry marks: 85
Enter Math marks: 88

Student 1:
Name: Alice
Roll No: 101
Physics: 90
Chemistry: 85
Math: 88
English: 80
CS: 92
Total: 435

Grade: B

## Concepts Used

- arrays
- strings and `strcmp`
- loops
- conditionals
- sorting logic
- user input and output
- grade calculation

## Learning Goal

This project helps practice working with arrays, total/average calculation, and basic data processing in C.
