# Math Menu Program

This folder contains a C program that displays a menu of mathematical operations and lets the user choose from the following:

1. Palindrome
2. Fibonacci Sequence
3. Perfect Square Sequence
4. Perfect Cube Sequence
5. Armstrong Number

## File
- `main.c`

## How to run
```bash
gcc main.c -o math_menu
./math_menu
```

## Example
The program asks the user to enter a choice and then performs the selected operation.

This project is part of the `c_basics` repository and was created for learning C programming basics.
