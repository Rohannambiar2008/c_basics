# Prime Number Checker

This folder contains a C program that checks whether a user-entered number is prime or not.

## File
- `main.c`

## How to run
```bash
gcc main.c -o prime_checker
./prime_checker
```

## Example
```text
Prime Number Checker
Enter a number: 17
17 is a prime number
```

## Concepts Used
- `for` loops
- conditional statements
- modulus operator
- input/output handling

This project is part of the `c_basics` repository and is a beginner-friendly practice program for learning loops and logic in C.
