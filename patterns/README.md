# Patterns

This folder contains beginner-level C programs that focus on pattern printing using `switch case` and nested loops.

## Purpose

These programs help practice:
- `switch` statements
- `for` loops
- nested loops
- user input handling
- output formatting

## Files

### 1. Pattern_Switch_case.c
This program prints:
- a triangle
- a square

The user selects the pattern using a menu.

### 2. Pattern_switch_case_part2.c
This program prints four different triangle styles based on user input:
- right inclined triangle
- inverted right inclined triangle
- left inclined triangle
- inverted left inclined triangle

## How to Run

### Compile the first program
```bash
gcc Pattern_Switch_case.c -o pattern1
./pattern1
```

### Compile the second program
```bash
gcc Pattern_switch_case_part2.c -o pattern2
./pattern2
```

## Learning Goals

These exercises are useful for understanding:
- control flow in C
- loop logic
- nested iteration
- pattern building through spacing and stars (`*`)

## Notes

These are beginner pattern programs and are intended for practice before moving to arrays, strings, functions, and pointers.
